# IMPORTANT
# - Do not modify/remove: %s, %d, %u, %1, %2 or similar. They are replaced by the game with custom strings and numbers.
# - Do not modify/remove: \n (it moves the text following it to the next line).
# - Lines starting with '#' are comments and do not need to be translated.
# - Lines starting with '@' define a '@token=localized text', and must end on the same line. Some have custom line splits added by using the \n characters, keep those when translating to avoid breaking the formatting.
# - Lines starting with '@@' define a multi-line localized text. They need to be terminated with a '@' character, eg @@token=text@
# - Lines starting with '@#' define multiple texts for one single token name. The game will randomly pick one of the texts for a token.
