@@ed_help=
Shortcuts:
CTRL + E: open / close editor for the current map
ESCAPE or RClick: deselect
DEL: delete current selection
SHIFT + MouseWheel: rotate selection on Y axis (also press X or Z to rotate on other axes)
SHIFT + MouseWheel + Ctrl: rotate selection by 45 degrees
SHIFT + RClick drag: rotate selection on Y axis (press X or Z to rotate on other axes)
SHIFT + Click: add/remove to selection
ALT + Click: depth selection (repeat click in the same place to cycle selection though all entities in that spot)
Y + MouseWheel: changes the height of selection
CTRL + MouseWheel: scale selection
CTRL + Y: toggles Auto Y setting on selection
CTRL + click entity on the map: automatically selects that entity type from the entity panel
R: rotate randomly on Y (keep pressed while an entity is selected from the entity panel, to randomize its rotation)
H + move mouse: move selection
SPACE (hold): show in 3D perspective
SHIFT + ArrowKeys: will move all objects in a map in the given direction
CTRL + Click an editbox/scrollbox to manually edit its values


Groups:
Holding SHIFT while placing new objects will auto-create a group with all new objects
Click + SHIFT on a sub-item from a group allows moving that object alone from within a group


Painting shortcuts:
ALT + LClick / RClick: paint in the normals layer
SHIFT + paint: locks the direction of paint on X / Y
SPACE: show terrain only
[ / ] : increase / decrease brush size
SHIFT + MouseWheel: increase / decrease brush size
1 / 2 / 3 / 4 : select respective layer from the current painting material
CTRL + Click: pick(select) material from the mouse cursor location
R : Rotate brush 90 deg when pasting
